Super Guy: Escape from Evil's Island is a 2D platformer inspired by a game I enjoyed in my childhood. From a development perspective, my goal was to create a replayable experience within a small map, 
allowing me to focus on core platformer mechanics without the added complexity of designing multiple levels. The objective of the game is to survive on the island until the timer runs out and escape
aboard the evacuation plane, all while avoiding various enemy types.
